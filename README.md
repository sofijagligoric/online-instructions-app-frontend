# 🎓 OnlineInstructions

Aplikacija za instruktore i studente, razvijena u sklopu predmeta **Projektovanje softvera** na Elektrotehničkom fakultetu u Banjoj Luci.  
Omogućava objavljivanje oglasa, deljenje resursa za učenje i diskusiju na forumu.

## Tehnologije
- Frontend: React, Ant Design
- Backend: Spring Boot
- Baza: MySQL

## Funkcionalnosti
- Instruktori objavljuju oglase i materijale
- Studenti pretražuju resurse i komuniciraju na forumu
- Sistem komentara i ocenjivanja
- Registracija i prijava korisnika
